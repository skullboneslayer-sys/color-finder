A free Windows color picker. Select a pixel on your screen and copy its color values.

Run **Color Finder Setup.exe** to install the app, then open **Color Finder** from the Start menu OR Desktop.

1. Click **Find color**.
2. Point at the pixel you want and click to select it.
3. Click a displayed color value to copy it.

Press **Esc** or right-click to cancel a pick. Arrow keys move one pixel; holding Shift moves ten.

Displays HEX, RGB, HSL, HSV/HSB, approximate CMYK, RGB 0-1, and linear RGB.

Use top left arrow navigator to pop-out the "Palette" of saved colors. Right click > Remove color to delete. All other colors are NOT saved between restarts.

**List of keyboard shortcuts (Unchangeable):**
| Shortcut | Action | When it works |
|---|---|---|
| **Ctrl + Shift + C** | Start picking a color | While Color Finder is running, including from another application |
| **Ctrl + Alt + C** | Alternative global shortcut | Only if Ctrl + Shift + C could not be registered |
| **F8** | Start picking a color | Color Finder’s window has focus |
| **Space** | Start picking a color | **Find color** button has keyboard focus |
| **Arrow keys** | Move the pointer **1 screen pixel** | While picking |
| **Shift + Arrow keys** | Move the pointer **10 screen pixels** | While picking |
| **Enter** | Select the pixel under the pointer | While picking |
| **Esc** | Cancel the pick | While picking |
| **Page Up / Page Down** | Scroll saved colors one page | Keyboard focus is inside the palette |

Requires Windows 10 or later with .NET Framework 4.8 or later.
